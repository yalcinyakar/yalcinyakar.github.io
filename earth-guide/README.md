# EARTH — A field guide for off-world visitors

Live: https://yalcinyakar.github.io/earth-guide/

An independent GitHub Pages subproject. Buildless HTML, CSS and JavaScript.
The initial edition contains 39 sourced notes across 13 domains. It is a growing introduction, not a claim to contain all human knowledge.

## Editorial rules
- Preserve the first-contact framing while distinguishing established evidence, measured approximations, human conventions, open questions and proposed visitor precautions.
- Add meaningful sourced notes, not filler. Prefer primary institutions, open textbooks and research papers.
- Keep each entry original; do not reproduce copyrighted passages.
- Verify quantitative, contested, changing, legal and health claims against authoritative sources. Do not give species-specific medical advice for hypothetical visitors.
- Each note must include its publication/review date, category, evidence label and source links.
- Append stable unique entry IDs. Never renumber existing permalinks.
- Update the displayed entry count and review date when adding notes.
- Review knowledge gaps across all domains; rotate coverage. Science, mathematics, ecology, civilization, culture, history, health, technology and uncertainty all matter.
- Update sitemap lastmod only when content changes.
- Validate HTML, local links and JavaScript. Publish to main and verify Pages deployment.
- Keep the personal portfolio and unrelated subprojects unchanged.

## Visitor messages
Signal Wall uses a private Google Sheet and an anonymous Apps Script web app.
See signal-backend/SETUP.md and Code.gs. Set SIGNAL_ENDPOINT in guide.js only after owner deployment.
Until configured, sending stays disabled with an explicit status.
Visitors need neither email nor account. They consent to public publication.
New messages are pending; only approved rows are returned by the public read endpoint.
Keep this integration intact during automated content additions.
Never publish fictitious visitor messages or report delivery without a backend receipt.

## Visual and editorial direction
- Preserve the sober 1970s aerospace-documentary identity: navy, warm ivory, restrained blue, square technical panels and archival typography. No cartoon aliens, neon colours or playful stickers.
- Use assets/earth-silhouettes.webp as the hero and social image. It is an AI-generated fictional extraterrestrial silhouettes in blue-green mist, not a historical photograph. Do not add a visible FICTIONAL / AI-GENERATED badge; retain descriptive image alt text.
- Keep the visual design serious and institutional, but restore dry, deadpan, lightly troll-like humour throughout the hero, headings, interface and field notes. The contrast is intentional: an official-looking archive with witty narration. Preserve clear error states and verified factual content.
- This is an independent educational project, not NASA or an official government department.
