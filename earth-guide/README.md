# EARTH — A field guide for off-world visitors

Live: https://yalcinyakar.github.io/earth-guide/

An independent GitHub Pages subproject. Buildless HTML, CSS and JavaScript.
The initial edition contains 39 sourced notes across 13 domains. It is a growing introduction, not a claim to contain all human knowledge.

## Editorial rules
- Preserve the first-contact framing while distinguishing established evidence, measured approximations, human conventions, open questions and proposed visitor precautions.
- Add meaningful sourced notes, not filler. Prefer primary institutions, open textbooks and research papers.
- Keep each entry original; do not reproduce copyrighted passages.
- Verify quantitative, contested, changing, legal and health claims against authoritative sources. Do not give species-specific medical advice for hypothetical visitors.
- Each note must include its publication/review date, category, evidence label and source links.
- Append stable unique entry IDs. Never renumber existing permalinks.
- Update the displayed entry count and review date when adding notes.
- Review knowledge gaps across all domains; rotate coverage. Science, mathematics, ecology, civilization, culture, history, health, technology and uncertainty all matter.
- Update sitemap lastmod only when content changes.
- Validate HTML, local links and JavaScript. Publish to main and verify Pages deployment.
- Keep the personal portfolio and unrelated subprojects unchanged.

## Visitor messages
The form prepares a GitHub issue titled [Earth Guide]. It redirects to GitHub for user review and submission; it does not submit or store a message by itself.
Messages are public, require a GitHub account and are readable at:
https://github.com/yalcinyakar/yalcinyakar.github.io/issues?q=is%3Aissue%20%22%5BEarth%20Guide%5D%22
No secret tokens are embedded in the client. No claim of anonymous or private delivery.
